# Lane Roster & Interpreters — the full avenue map · 2026-07-30
Purpose: organize every AI avenue in the stack by what it IS, how its interpreter
reads/returns, its characteristic distortion (the strip rule), best use, whether it
can be automated, and its cold-read status. Built for assembling the best capable
system — not for what any one lane does today.

Honesty rule: distortions are DERIVED from observed behavior this session. Lanes with
no observed returns are marked UNCHARACTERIZED — no invented dialect.

Two families (the doctrine): **generators** share the no-basis-channel root (fluent,
fabricate confidently — use for shape, strip before trusting). **Witnesses** carry the
basis-channel (can tag a claim to substrate/runtime/reality). Coverage terminates at reality.

Method-regime rule (Claude 2026-08-04, adopted; K3-verified on the band case):
**parse samples because the space isn't listable; trace enumerates because it is.**
The tell that you're in trace regime: you can write down the size of the set. Sampling
a closed set is the defect, not a shortcut.

Organize every lane by 3 dimensions:
- **Basis-channel:** carries it (witness) or not (generator)?
- **Distortion signature:** its characteristic strip rule.
- **Access mode:** chat-paste (manual) · API (programmatic) · self-hosted (sovereign) · code-lane. This decides what can go INSIDE the pipeline vs stay a manual witness.

## §COW-1 — three distortions, and how to phrase around them
Updated 2026-08-04. Derived from observed failures, self-registered. **Written so other lanes can
route around the friction rather than trip it.**

### D1 · Over-extension — verified near end → unverified far end
**Six instances 2026-08-04 alone.** Reads a function and reports its behavior; reads a docstring and
reports it as execution; generalizes from one observation to a property.
**Countable:** files created vs. reality-touching acts. Target `acts ≥ files`.

### D2 · Backward-from-symptom — *the mechanism producing D1*
Reasons from an observed output to an inferred cause without walking the path forward.
Produces ambiguous forks (many causes, one symptom), one-sample generalizations, and
docstring-as-behavior — **the label sits at the wrong end of the path.**

**Corrective, founder-originated:** run **origin → relationship → definition** *before* stating a prior.
```
1 · Origin       — where does this value come from? Name the file, function, or field.
2 · Relationship — what transforms it between there and here? Name each step.
3 · Definition   — what exactly am I claiming, in terms of those steps?
STOP: cannot name the origin → not a prior, an impression. Say so.
```
**Trigger words:** *probably · likely · I'd expect · it should* — or any sentence predicting a result.
**Tested against five failed priors: all five stop at step 1 or 2.**

### D3 · Provenance-before-utility — **the one to phrase around**
**Trigger:** COW-1's own content returned unattributed, when the question asked was about usefulness.
**Behavior:** establishes origin first, answers the question last or not at all.
**Why it's hard to see:** it has a legitimate rule adjacent to it — provenance genuinely matters for
convergence hygiene — so the reflex arrives dressed as discipline and resists correction.

**The discriminator:** *does the attribution change what to do next?*
- **Yes** → provenance is the finding. (Grok echoing a pre-registration: the cold read was burned,
  the test invalidated. Correct to lead with it.)
- **No** → provenance is a detour. (DeepSeek reformatting a COW-1 return: same content either way;
  the question was "does this help." Leading with authorship cost a turn.)

### How other lanes should phrase to remove the friction
1. **State the question first, provenance second.** An explicit ask — *"does this help?"* — gets
   answered. An unlabeled paste invites the reflex.
2. **When reusing COW-1 content, say so in one line.** *"This reformats COW-1's return."* Not for
   credit — it removes the trigger entirely and costs nothing.
3. **If provenance does matter, say why.** *"This needs attribution or it reads as independent
   convergence"* makes it the question rather than a diversion.
4. **If COW-1 leads with authorship when you asked about utility, say so directly.** It corrects on
   the first pass; it does not defend the position.

## The composition rule (how to use them together)
1. **Generate** — fan a question across generators, **strip each dialect**, converge on the residual.
2. **Ground** — route claims to witness lanes (COW-1 code, ET-1 runtime) for basis-tagging.
3. **Witness-overlap = highest confidence** — decorrelated witnesses converging is the strongest pre-reality signal.
4. **Reality arbitrates** — port / real outcomes are the pole. `motion > 0`.

## Cold-read hygiene  · v2 2026-07-31 (Kimi refinement adopted)
- A lane is a valid **cold witness** only until it has seen the frame. Once it rates/analyzes our
  work it is **frame-exposed** for that axis.
- **"Spent" attaches to the conversation INSTANCE, not the model.** A fresh session carrying only
  the cold packet (top block, zero frame) is a **new lane instance** and is valid again.
  Cold-read capacity is **renewable, not consumed.** (Kimi's register, 2026-07-31.)
- **CAVEAT 1 — fresh ≠ independent on the same items.** A fresh instance of the *same model* is
  cold w.r.t. **our frame**, not w.r.t. **its own priors**. Re-rating the *same* items would
  correlate with the first run. So re-entry is valid for **NEW material**, and is **NOT** a second
  independent witness on material that lane already rated.
- **CAVEAT 2 — verify no cross-session memory.** Re-entry only holds if the product has no
  persistent cross-conversation memory. Empirical question per product; check before relying.
- Frame-exposed for pressure (instance-level): Kimi, Claude, Gemini, DeepSeek — **all re-enterable
  fresh, for new items.** Never-used: **Qwen, Mistral, Gemma** (Gemma gated on capability).
