### Universal Primitive–Geometry–Terminal Compiler (UPGT)

Below is a compact artifact you can drop into your resource stack and wire into the existing tools.

---

## 1. Conceptual spec

**Purpose:**  
Provide a domain‑agnostic spine that lets any tool map:

> **Primitive → Geometry → Terminal → Burden → Next Move**

across legal, organizational, emotional, infrastructural, or social systems.

**Core ideas:**

- **Primitive:** A universal failure mode or dynamic (boundary collapse, signal contamination, narrative gravity, etc.).
- **Geometry:** The shape of the system under that primitive (curvature, coherence, agency vector, trend, jerk, temporal pull, frame origin).
- **Terminal:** The system’s endpoint/failure state (boundary terminal, coherence terminal, authority terminal, flow terminal, temporal terminal, normalization terminal, identity terminal).
- **Burden:** What must be shown, changed, or supplied to move out of that terminal.
- **Next Move:** The concrete action in the relevant domain (e.g., FRCP move, org intervention, emotional regulation step, infra mitigation).

## 3. Canonical primitive set (for shared use)

You can store these as rows in your metadata layer:

- **Boundary Collapse**
- **Signal Contamination**
- **Narrative Gravity**
- **Flow Collapse**
- **Normalization Sink**
- **Archive Gravity**
- **Authority Drift**

Each tool (FRCP compiler, Organizational Godhard, CROSSREGRESSION, SOCIAL_SUM, etc.) attaches its own **domain_adapter** entries pointing to its specific terminals and moves.

---

## 4. Integration hooks with existing tools

When you wire this into your stack, each tool should:

- **Ingest primitives** from UPGT rather than defining its own ad‑hoc set.
- **Write geometry fields** (curvature, coherence, agency vector, trend, temporal pull) back into UPGT.
- **Register terminals**:
  - FRCP tool → legal terminals (12(b)(6), Rule 56, etc.).
  - Organizational tool → org terminals (catastrophic transition, coherence loss, authority hijack).
  - CROSSREGRESSION → infra strain terminals (overload, failure, latent risk).
  - Emotional‑reg tool → emotional terminals (shutdown, hypervigilance, dissociation, compulsive normalization).
- **Bind tool actions** to `domain_adapter.next_move`.

That gives you one shared spine instead of parallel, slightly‑different primitive sets.
